# Mundo Huellitas - Backend 🐾

**Todos merecen un hogar.**

## Descripción

Backend de Mundo Huellitas, una aplicación móvil que busca facilitar la adopción responsable de mascotas, conectando a personas interesadas en adoptar con refugios que buscan un hogar para los animales.

## Objetivo

Gestionar la información y las funcionalidades necesarias para el funcionamiento de la aplicación.

## Tecnologías

- Node.js
- Express
- MongoDB
